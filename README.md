# Shriram Mange Resume Website

A clean and professional CV/resume website built using HTML and CSS. This project showcases personal details, education, skill sets, work experience, and project highlights in a single-page format.

## Overview

This repository contains a static resume website for Shriram Mange, designed to present:

- Personal contact details
- GitHub and LinkedIn links
- Professional summary
- Project experience
- Education history
- Technical skills
- Experience and certifications
- Additional personal information

## Tech Stack

- HTML5
- CSS3
- JavaScript (included as a placeholder file)

## Project Structure

```text
Resume-Website-Practical/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Features

- Responsive single-page resume layout
- Structured sections for easy readability
- Clean professional styling
- Easy to customize for personal branding
- Static website — no backend required

## How to Run

Since this is a static webpage, you can run it in either of the following ways:

1. Open `index.html` directly in your browser.
2. Or serve the project locally:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000/
```

## Customization

To personalize the resume:

- Update the name, contact info, and social links in `index.html`
- Edit the description, projects, education, and skills sections
- Modify colors, spacing, and layout in `style.css`

## Notes

This project is ideal for learning basic front-end development, especially:

- semantic HTML structure
- CSS layout and typography
- building portfolio or resume pages without frameworks
